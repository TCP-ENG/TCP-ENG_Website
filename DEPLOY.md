# Deploying to Cloudflare Pages

This site is a **static export** (`output: "export"` in `next.config.mjs`) — `npm run
build` produces a fully static `out/` folder with no server. That deploys directly to
**Cloudflare Pages**; no SSR adapter (`@cloudflare/next-on-pages`) is needed.

## One-time setup (Cloudflare dashboard → git integration)

1. **Workers & Pages → Create → Pages → Connect to Git** → pick
   `TCP-ENG/TCP-ENG_Website`.
2. **Build settings:**
   | Setting | Value |
   |---|---|
   | Framework preset | **Next.js (Static HTML Export)** — or **None** |
   | Build command | `npm run build` |
   | Build output directory | `out` |
   | Root directory | *(leave blank — repo root **is** the Next.js project)* |
   | Node version | **20** (from `.nvmrc`; or add build env var `NODE_VERSION=20`) |
   | Environment variables | none required |

   > Pick the **Static HTML Export** preset (or **None**). Do **not** pick a preset that
   > builds with `@cloudflare/next-on-pages` — this site is static and doesn't need it.

3. **Save and Deploy.** Cloudflare runs `npm ci && npm run build` and serves `out/`.

## Custom domain

- **Pages project → Custom domains → Set up a domain** → `tcp-eng.com`.
- For `www` → apex, add a **Cloudflare Redirect Rule**: `www.tcp-eng.com/*` →
  `https://tcp-eng.com/$1` (301). (Redirect Rules handle cross-host redirects better
  than a `_redirects` file.)

## What's already configured in this repo

- **`.nvmrc`** → Node 20 for the build.
- **`public/_headers`** → long-cache for hashed `/_next/static/*`, media caching, and
  security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`,
  `Permissions-Policy`). A ready-to-enable CSP is included as a comment.
- **`public/robots.txt`** + **`public/sitemap.xml`** → served at the site root.
- **`404.html`** → generated by the export; Cloudflare serves it for unknown URLs.
- **Clean URLs** → `trailingSlash: true` emits `/about/index.html`, etc.

## Branch → deploy mapping (see BRANCHING.md)

- Pushes to **`main`** → **production** deployment (`tcp-eng.com`).
- Every other branch / PR → a **preview** deployment at a unique `*.pages.dev` URL —
  review there before merging.

## CLI alternative (optional)

```bash
npm run build
npx wrangler pages deploy out --project-name tcp-eng-website
```

## Before going live — owner to-dos

- Replace `YOUR_FORM_ID` in `app/contact/page.js` with a real Formspree form ID.
- Run Lighthouse (mobile) and confirm the site at the three breakpoints (375 / 768 / 1440).
